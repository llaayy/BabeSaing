# For My Love

A responsive, single-page romantic website inspired by a handwritten love letter.

## Run it

Open `index.html` in any modern browser. No installation or server is required.

## Make it yours

- Replace `[your name]` in `index.html`.
- Replace the letter, memories, and four reasons with your own words.
- Put photos in `assets/images/`, then replace a photo placeholder with `<img src="assets/images/your-photo.jpg" alt="A memory of us">`. Add `class="memory-image"` to the image.
- Put your song in `assets/audio/` and update the audio filename near the top of `index.html`. The current song is `1012.mp3`; the sound button plays or pauses it.
- Colors and typography are grouped at the top of `style.css`.
- The opening envelope screen text is at the top of `index.html`; clicking it reveals the full letter site.

The sound switch is a visual touch only. Add an audio file and playback logic in `script.js` if you would like it to play music.
